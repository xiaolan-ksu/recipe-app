# 今天吃什么 🍚

> 一日三餐，人间烟火。一个专治「选择困难」的家常菜谱 App。

每天最难的问题不是「吃什么菜」，而是 **今天吃什么**。这个 App 打开就是一道菜，
不想吃就换一个；冰箱里有什么、还差什么、要花多少钱，都给你算清楚。

基于 **React Native + Expo SDK 57 + TypeScript**，安卓为主，同一套代码也能跑网页版。

## 功能

| 功能 | 说明 |
| --- | --- |
| 🎲 **首页推荐** | 打开就是一道菜，一键换一个，不再纠结 |
| 📖 **103 道家常菜** | 10 个分类，每道都有实拍照片，可搜索 |
| 🧮 **用料自动换算** | 按家里人数自动折算食材用量与花费 |
| 🧊 **冰箱管理** | 勾选家里有的食材，立刻知道能做什么、还差哪几样 |
| ⏰ **保质期提醒** | 快过期的食材优先提醒，先吃掉不浪费 |
| 🛒 **买菜清单** | 按超市区域分组，勾一样减一样，买完一键入库 |
| 🚫 **忌口过滤** | 设一次就行，所有推荐自动避开 |
| 👫 **共享清单** | 两个人共用同一份清单和库存，对方几秒就能看到 |
| ☁️ **云更新 (OTA)** | 改界面改逻辑，手机直接下载，不用重新装 |
| ✍️ **自己加菜** | 拍照、写做法，加进自己的菜谱库 |

## 快速开始

```bash
# 1. 安装依赖（需要 Node 20+ 与 pnpm）
pnpm install

# 2. 手机扫码运行（需装 Expo Go）
pnpm start

# 3. 或在电脑上跑网页版
pnpm web
```

## 项目结构

```
├── App.tsx              # 应用入口
├── src/
│   ├── screens/         # 页面：首页 / 菜谱 / 食材 / 买菜 / 我的
│   ├── components/      # 通用组件
│   ├── lib/             # 业务逻辑（忌口、推荐、共享、云更新）
│   ├── store/           # zustand 状态管理（本地持久化）
│   ├── data/dishes.ts   # 103 道菜数据（脚本生成，勿手改）
│   └── theme.ts         # 配色与字体
├── server/              # 后端：共享清单 + OTA 更新服务
├── assets/dishes/       # 菜品实拍图
├── docs/                # 文档与截图
└── work/                # 菜谱数据生成脚本
```

## 后端（可选）

「共享清单」和「云更新」需要自建后端。`server/` 是一个零依赖的 Node + SQLite 服务：

```bash
cd server
node app.js          # 共享清单 API
```

配置后端地址（不改代码）：

```bash
EXPO_PUBLIC_API_BASE="https://your-domain.com" pnpm start
```
