## 一句话

做一个装在你手机上的小应用，每天帮你决定今天吃什么家常菜，不喜欢就换一道。

## 做好以后你怎么用

打开 App，先看到今天推荐的一道菜；不满意，点「换一个试试」；想学着做，点进菜谱看要买什么、怎么做；合口味的点个收藏，下次好找。手机没网也能用。

## App 有 5 个页面

就是你发的那张图最下面那 5 个按钮：

| 页面 | 干什么 |
| --- | --- |
| 首页 | 今天吃什么，一次推一道，能换、能收藏 |
| 菜谱 | 所有菜都在这里，点进去看用料和做法 |
| 食材 | 勾一下家里有什么，反推能做什么菜 |
| 买菜 | 要买的东西记在清单里，买一样勾一样 |
| 我的 | 收藏的菜、做饭记录、口味设置 |

## 分三步做，每步你都能看到东西

**第一步：只做首页。**
把家常菜的图片和推荐功能先做好。做完你把手机拿出来扫个码，就能看到和你发的图一样的界面，能换菜、能收藏。这一步最重要，也最能看到效果。

**第二步：加菜谱页和详情页。**
点进去能看到每道菜要买哪些料、分几步做、大概花多少钱。还能按家里几口人自动换算出用量。

**第三步：加食材、买菜、我的三个页面。（已完成）**
勾选冰箱里有什么就能推菜，要买的记进清单，收藏和做饭记录都存下来。
买菜清单勾完可以一键「入库」，买到的食材自动出现在食材页；食材页里缺的那几样可以一键加回买菜清单。

最后：把 App 打包成一个安装包，装到你自己手机上。以后不用开电脑，点开就能用。（**已完成**）
