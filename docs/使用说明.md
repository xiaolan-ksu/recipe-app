# 怎么看这个 App（大白话版）

三步都做完了：首页、菜谱、菜谱详情、食材、买菜、我的，一共六个页面都能用。

---

## 一、在手机上看（推荐）

1. 手机应用商店里搜 **Expo Go**，装上（免费，不用注册）。
2. 手机连上家里的 Wi-Fi，电脑也要连着同一个 Wi-Fi。
3. 在电脑上打开文件夹 `<项目根目录>`，双击 **`1-手机扫码运行.bat`**。
4. 会弹出一个黑窗口，里面有一个二维码——**这个窗口不要关**。
5. 用手机上的 Expo Go 扫那个二维码，App 就出现在手机上了。

如果扫码没反应，可以在 Expo Go 里选「手动输入地址」，输入：

```
exp://192.168.31.110:8081
```

（这个地址是你家电脑现在的局域网地址。以后换了 Wi-Fi 可能会变，到时告诉我。）

看完想关掉：在黑窗口里按 `Ctrl + C`，或者直接关窗口。

## 二、在电脑上看

双击 `<项目根目录>` 里的 **`2-电脑上预览.bat`**，浏览器会自动打开。

屏幕上会显示一个手机外框，中间那块就是 App 的样子，跟你的参考图一样。

## 三、现在能做什么

| 页面 | 现在能干什么 |
| --- | --- |
| 首页 | 一次推一道菜，点「换一个试试」换下一道；点右上角爱心收藏；点卡片看详细做法 |
| 首页左上角·位置 | 显示手机定位到的真实地址（比如「上海市 · 静安区」）；点一下可以重新定位，或者自己手填一个 |
| 分类 | 全部 / 快手菜 / 下饭菜 / 汤羹，点一下只看这一类 |
| 筛选偏好 | 首页右上角的按钮：设家里几口人、不吃什么、口味偏好，推荐会自动避开忌口 |
| 菜谱页 | 103 道菜全都在这里（10 个分类：猪肉类、牛肉类、鸡肉类、鱼虾海鲜、素菜、蛋豆、凉菜、汤、主食），**每道菜都有实拍的照片**，能搜索（菜名、食材、做法都能搜）、能按最快 / 最便宜 / 最受欢迎排序 |
| 菜谱详情 | 要买什么、每样多少、大概花多少钱；改人数用料自动换算；分步骤做法和小贴士；底部「加入买菜清单」 |
| 食材页 | 按蔬菜、肉禽蛋、豆制品、调味、主食分组，勾一下家里有什么；下面立刻列出「能做什么菜」，并写明每道菜还差哪几样；缺的可以一键加进买菜清单 |
| 食材页·保质期 | 每样食材都有到期日（蔬菜 5 天、肉蛋 3 天、豆制品 2 天…）；快过期和已过期的排最前面，页面上会提醒「先吃掉这些」；点「保质期」可以一样一样加减天数，或者标记「吃掉了」 |
| 买菜页 | 清单按超市区域（蔬菜区、肉禽蛋区…）分好；买一样勾一样，勾掉的自动从总价里减掉；数量能加减；底部随时显示「还要买几样 · 预计多少钱」 |
| 买菜页·入库 | 勾完点「买完了入库」，买到的食材自动记进食材页，下次推荐就能用上 |
| 我的页 | 收藏的菜、做饭记录（打分 + 写一句话）、连续认真吃饭天数、家庭人数和忌口口味，都在这里改 |
| 我的页·头像昵称 | 点左上角头像、昵称或者「点这里换头像、改昵称」都能改：头像可以从相册选一张，也可以现拍一张，不想要了还能换回默认的小人；昵称最多 12 个字 |
| 我的页·共享清单 | 和另一个人共用一份买菜清单和冰箱库存。一方点「我来创建」，拿到一个 6 位家庭码；另一方在自己手机上输入这个码就加入了。之后谁往清单里加东西、谁勾掉、谁买回来点「入库」，对方**过几秒就能看到**。家庭码 24 小时内有效、用过一次作废，随时可以在面板里重新生成 |
| 我的页·版本与更新 | 看现在装的是哪一版（当前版本 9.1.2），点一下就能检查有没有新版本。改界面、改文字的更新**下载一下就好，不用重装**；万一动到了安卓本身，面板里也能直接把新安装包下下来装（详见 `云更新怎么用.md`）|
| 自己加菜 | 菜谱页右上角「加菜」，或者「我的 → 我加的菜 → 加一道」：填菜名、分类、用料、做法，可以配一张相册里的照片；加完能改能删，也会一起进推荐、搜索和买菜清单 |
| 菜谱页·删掉自己加的菜 | **只有自己加的菜**，卡片右下角（爱心下面）有个垃圾桶，点一下问你一句，确认就删掉——删了就找不回来了。菜谱自带的那 103 道不提供删除 |

收藏、口味偏好、人数、头像和昵称都会存在手机里，下次打开还在。

## 四、装到手机上（安装包已经打好了）

安装包：`outputs\今天吃什么-9.1.2-安卓.apk`（55 MB，版本号 9.1.2）

传到手机上点开就能装，装完桌面上有个「今天吃什么」的图标，**以后不用开电脑**。第一次装系统会问「是否允许安装未知来源的应用」，允许一下即可；装完提示「未经检测」也正常（自己做的包没上应用商店）。

这个包里有：103 道菜的完整菜谱、手机真实定位、食材保质期提醒、自己加菜/改菜/删菜、自定义头像和昵称、能左右滑动的分类栏、**两个人共用的买菜清单**，以及**云更新**（以后改东西不用再重新装包了）。

装新包直接覆盖旧的就行，收藏、记录、头像这些数据都在（`outputs` 里只留最新这一个包）。
> 注意：手机上原来那个包装不了云更新（它的底座里没有这套代码），所以**这一版 9.1.2 还得手动装一次**；从这版开始，以后的小改动就都能云端更新了（版本号会一路 9.1.3、9.1.4 涨上去）。

更细的步骤（怎么传到手机、各种品牌手机的提示怎么点）见同目录的 `安装包-怎么装.md`。

上面第一、二节的 Expo Go 扫码方式仍然可以用——改了代码想马上看效果时，用扫码比重新打包快得多。

### 以后怎么改？（云更新）

从 9.1.2 开始，改完之后不用再重新打包传手机了：

1. 我改代码 → 推一个更新到服务器；
2. 你手机上打开 App，它会自己把新版下好，下次打开就是新的；
3. 想马上换：**我的 → 版本与更新 → 再检查一次 → 下载 → 马上重启**。

只有极少数情况（动到安卓本身）才需要重新装一次安装包，那时候面板里会直接告诉你，点一下就能下载安装。细节看同目录的 `云更新怎么用.md`。

## 五、几个说明

- 图片和菜谱都打包在 App 里，**没网也能看**。
- 共享清单（**只有这一块会联网**）：配对之后，买菜清单和冰箱库存会同步到你自己那台服务器（`YOUR_SERVER_IP:8080`），另外一个人才能看到。收藏、做饭记录、口味、头像这些**不上传**，还是只在这台手机上。没网的时候照样能改清单，改动先存在手机上，一联网就自动补上去。
- 位置：第一次打开会问一次定位权限，同意后首页左上角就显示你所在的城市和区。地址只存在这台手机上、不会上传；没给权限会显示「点击允许定位」，查不到具体地名时会退回显示经纬度，也可以自己手填一个。
- 自己加的菜：菜和照片都存在手机里；照片会复制到 App 自己的文件夹，清理缓存不会丢。用料的「¥单价」填了，买菜清单的总价才算得准。
- 用 Expo Go 这种方式，每次要在电脑上点一下启动脚本。以后想真正「装到手机上、不用电脑」，我再给你打一个安装包（就是计划里说的最后一步）。
- 想改配色、改菜、改文字，或者哪句话看着别扭，直接跟我说。
